# Summary of Xenea

Source: [https://docs.xenea.io/](https://docs.xenea.io/)

Xenea is an EVM-compatible Layer 1 blockchain with integrated autonomous decentralized storage.

Key points:
- EVM-compatible for existing smart contract workflows
- PoD consensus for decentralized voting and validation
- DACS storage to keep data persistent and consistent

Xenea positions itself as infrastructure for long-lived digital assets, NFTs, and AI/DePIN-style data workloads.
