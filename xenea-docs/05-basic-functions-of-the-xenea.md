# Basic Functions of the Xenea

Source: [https://docs.xenea.io/whitepaper/basic-functions-of-the-xenea](https://docs.xenea.io/whitepaper/basic-functions-of-the-xenea)

This chapter explains the main building blocks of Xenea:

- PoD consensus
- XENE token economy
- DACS storage

The doc also notes that XENE transfers are intended to be free, while token/NFT activity uses minimal fees.
