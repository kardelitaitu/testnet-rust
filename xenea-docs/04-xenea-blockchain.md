# Xenea Blockchain

Source: [https://docs.xenea.io/whitepaper/xenea-blockchain](https://docs.xenea.io/whitepaper/xenea-blockchain)

The blockchain chapter describes Xenea as an original Layer 1 protocol based on peer-reviewed research.

It highlights:
- voting-based consensus
- smart contract support
- autonomous decentralized storage

The doc positions Xenea for dApps such as DeFi, NFT marketplaces, and other Web3 systems.
