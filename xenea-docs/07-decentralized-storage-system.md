# Decentralized Storage System

Source: [https://docs.xenea.io/whitepaper/decentralized-storage-system](https://docs.xenea.io/whitepaper/decentralized-storage-system)

This chapter covers DACS and the Sustainable Generation Manager concept.

Main points:
- content hashes are recorded on-chain
- distributed file systems are linked to the blockchain
- storage is meant to remain durable over time

The doc focuses on NFT and large-content persistence rather than short-lived off-chain storage.
