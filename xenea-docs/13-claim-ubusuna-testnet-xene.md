# Claim Ubusuna Testnet XENE

Source: [https://docs.xenea.io/testnet/claim-ubusuna-testnet-xene](https://docs.xenea.io/testnet/claim-ubusuna-testnet-xene)

The testnet faucet flow is:
- join the Xenea Discord
- verify the Discord account
- go to the faucet channel
- use the `/faucet` command with your wallet address

The page instructs users to confirm the transaction in XENEA Scan after claiming.
