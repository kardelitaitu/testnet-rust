# Introduction

Source: [https://docs.xenea.io/whitepaper/introduction](https://docs.xenea.io/whitepaper/introduction)

Xenea is described as a storage layer for the AI and DePIN era.

Core themes:
- secure storage across generations
- EVM-compatible Layer 1 execution
- PoD for fair voting and resilience
- DACS for decentralized content storage

The emphasis is on keeping datasets permanent, verifiable, and usable for future applications.
