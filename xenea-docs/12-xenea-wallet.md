# XENEA Wallet

Source: [https://docs.xenea.io/whitepaper/xenea-wallet](https://docs.xenea.io/whitepaper/xenea-wallet)

XENEA Wallet is described as a compatible wallet for the Xenea ecosystem.

Notable ideas:
- wallet layer plus voting module
- designed to reduce private-key management stress
- phased rollout for mining participation

The page suggests wallet and mining features will be expanded over time.
