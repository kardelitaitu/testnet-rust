# XENE Tokenomics

Source: [https://docs.xenea.io/xene-tokenomics-1.0/xene-tokenomics](https://docs.xenea.io/xene-tokenomics-1.0/xene-tokenomics)

XENE tokenomics is presented as the incentive layer for Xenea.

It is used for:
- network security
- decentralization incentives
- ecosystem development
- storage collateral

The token model is tied to node participation and application growth.
